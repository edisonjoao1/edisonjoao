# Edison Espinosa - Portfolio Website

**Live Site**: [edisonjoao.com](https://edisonjoao.com)

## Overview

This portfolio website showcases Edison's Principal PM work, featuring measurable business impact across B2B, SaaS, and consumer products. The site emphasizes data-driven execution, strategic thinking, and product-led growth.

## Current Focus: Principal PM Work

The website currently focuses on:
- **Product Portfolio Management**: 50+ projects across B2B, SaaS, B2C, and consumer markets
- **Automation & Scaling**: Building systems that compound (57 posts/day automated, B2B pipeline automation)
- **Strategic Execution**: Blue ocean strategies, rapid MVPs (24-hour launches), conversion optimization
- **Full-Stack AI Development**: AI agents, automation tools, content generation systems

### Key Metrics Highlighted
- 1M+ users across products
- 4.48% peak conversion rate (2x industry average)
- $1M+ processed through products
- 50+ projects led throughout career
- Worldwide user base

## Tech Stack

- **Frontend**: React + TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Build Tool**: Vite
- **Deployment**: Vercel/custom hosting

## Key Sections
